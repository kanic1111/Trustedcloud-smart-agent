金鑰
建立 API 金鑰
點擊右上角的使用者名稱，再點選 金鑰 進入 API 金鑰管理頁面，接著點擊「＋建立」。
輸入 API 金鑰名稱後點擊「建立」。
API 金鑰建立後，請立即點擊「下載」並妥善保存此金鑰。
管理 API 金鑰
API 金鑰建立後會出現在列表中。
删除 API 金鑰
點擊 API 金鑰列表右側的更多選項圖示，再點擊「刪除」。
S3 金鑰
點擊右上角的使用者名稱，再點選 金鑰。
接著點擊左側選單 S3 金鑰，進入 S3 連線資訊頁面。
S3 連線資訊頁面提供 Access Key 及 Secret Key 等資訊。
點選右上方「下載 S3 BROWSER」可開啟 S3 BROWSER 官方網站下載 S3 BROWSER 或取得更多資訊。
點選右上方「更新金鑰」可更新您的金鑰。
金鑰使用提示
1. 此 S3 金鑰無預設期限，一旦在第三方軟體中設定好，下次開啟第三方軟體時直接連線即可。
2. 請妥善保管您的金鑰，或定期更新金鑰，以防金鑰外流。金鑰更新後，請記得更新第三方軟體中的金鑰設定。
公開存取金鑰
您可以配置自有的公開存取金鑰以便存取相關的服務或應用。
點擊右上角的使用者名稱，再點選 金鑰。
接著點擊左側選單 公開存取金鑰，進入公開存取金鑰頁面。
在輸入框中貼上公開金鑰，再點擊「更新」。
也可以貼上多組公開金鑰，再點擊「更新」。
點擊「還原」可將輸入框中的內容還原成最後儲存的內容。
