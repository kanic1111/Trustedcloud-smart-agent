自動擴展
自動擴展服務是一種自動彈性調整的監控機制，能夠在指定條件下動態新增或移除虛擬機器的數量，以因應負載增加所造成的資源不足、服務中斷的問題，提升服務品質與效能。
負載達到需求值後擴展數量，低於需求值便立即縮減，並搭配負載平衡功能讓流量平均分配，可有效降低長時間建立空閒之虛擬機器成本。
建立自動擴展
從服務列表選擇 自動擴展 進入自動擴展管理頁面，接著點擊「＋建立」。
1. 基本設定
名稱：輸入自動擴展的名稱。
描述：輸入自動擴展的描述。
虛擬網路：選擇虛擬網路。
Metric：選擇 cpu 或 memory，此為判斷是否擴展、縮減虛擬機器數量的資源使用率指標。
閾值上限：設定 Metric 的最高閥值。例如：若當 Metric 為 cpu 時，此數值設定 80 即代表 CPU 的使用率超過 80% 時將自動擴展虛擬機器數量。
閾值下限：設定 Metric 的最低閥值，低於此閥值時則會自動縮減虛擬機器數量。
虛擬機器上限：設定虛擬機器數量的最大上限。
虛擬機器下限：設定虛擬機器數量的最少下限。
接著點擊「下一步：虛擬機器規格＞」。
2. 虛擬機器規格
映像檔來源：選擇映像檔來源。
映像檔標籤：選擇映像檔標籤。
查看資源使用量 / 配額：可檢視目前的資源配額及已用量。若可用資源配額已達上限，部分型號無法選擇，可聯繫您的系統管理員提高專案資源配額。
硬體設定：選擇硬體規格。
安全群組：選擇安全群組。
鑰匙對：（選擇性）選擇 啟用 或 關閉 鑰匙對認證，若啟用鑰匙對，接著需選用一組鑰匙對。
密碼：設定初始密碼。
初始化指令：（選擇性）輸入或滙入初始化指令。
接著點擊「下一步：檢閱＋建立＞」。
3. 檢閱＋建立
檢查建立設定，確定後點擊「建立」。
管理自動擴展
自動擴展建立後會出現在列表中，點擊列表右側的更多選項按鈕可執行 複製服務 ID 及 刪除。
點擊列表可查看服務的詳細資料，當狀態呈現 active 即可開始使用。當負載達到需求值後擴展虛擬機器數量，低於需求值便立即縮減。
進入自動擴展詳細資料頁面，可編輯描述、虛擬機器上限、虛擬機器下限、閾值等設定。
删除自動擴展
點擊列表右側的更多選項圖示，再點選 删除。
批次删除
若想快速刪除多個資源，可點擊管理頁面右上方的「批次删除」。
勾選欲刪除項目後點擊「確定」。
停止／啟動虛擬機器
點擊上方 虛擬機器規格 頁籤，將滑鼠移至虛擬機器列表右側的更多選項按鈕，接著點擊 停止；若該虛擬機器已停止，此時選單中會顯示為 啟動。
重啟虛擬機器
點擊上方 虛擬機器規格 頁籤，將滑鼠移至虛擬機器列表右側的更多選項按鈕，接著點擊 重啟。
連線虛擬機器
點擊上方 虛擬機器規格 頁籤，將滑鼠移至虛擬機器列表右側的更多選項按鈕，接著點擊 Console。
在瀏覽器中開啟 Console 視窗後，使用建立自動擴展時設定的初始密碼，即可快速連線至虛擬機器。
登入帳號：若使用系統提供的公用虛擬映像檔預設帳號如下：
虛擬映像檔, 預設登入帳號
----------, --------
ubuntu, ubuntu
rocky, cloud-user
windows, administrator
配置浮動 IP／分離浮動 IP
點擊上方 虛擬機器規格 頁籤，將滑鼠移至虛擬機器列表右側的更多選項按鈕，接著點擊 配置浮動 IP。
點擊 虛擬機器規格 頁籤，在頁面下方的虛擬機器列表，將滑鼠移至右側的更多選項按鈕，接著點擊 配置浮動 IP；若該虛擬機器已配置浮動 IP，此時選單中會顯示為 分離浮動 IP。
配置完成後在列表中會顯示浮動 IP。
