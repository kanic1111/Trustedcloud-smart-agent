# 資料攜出

本服務可將本地檔案寫入至目標服務上之暫存空間。

:::warning 
:warning: **注意**： 本服務僅提供私區之寫入服務。
:::

## 建立儲存體
* 從服務列表選擇 **資料攜出** 進入資料攜出管理頁面，接著點擊「**＋建立**」。
* 輸入儲存體名稱後按下「**確定**」。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img1.png）

## 管理儲存體
* 儲存體建立後會出現在列表中，點擊該列表進入儲存體內容頁面即可開始使用。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img2.png）

### 删除儲存體
* 點擊儲存體列表右側的更多選項圖示，再點擊「**刪除**」。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img3.png）

* 確認欲删除的儲存體名稱後點擊「**確認**」。

:::warning 
:warning: **注意**：儲存體一旦删除，儲存體內所有的資料將會被全數删除，無法復原。專案內的儲存體為所有成員共用，任何修改或删除，都有可能影響群組內的使用者，請務必留意。
:::

### 查看用量
* 點擊管理頁面的「**查看用量**」，可查看專案的儲存用量資訊。

### 權限設定
* 您可為儲存體啟用權限設定功能，啟用權限設定後，有被加入的成員才可讀寫此儲存空間。
* 點擊儲存體列表右側的更多選項圖示，再點擊「**權限設定**」。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img4.png）

* 完成權限設定後點擊「**確定**」。
    - 權限設定：選擇 **啟用** 或 **停用**。
    - 新增成員：啟用權限設定後，接著從下拉選單中選取欲新增的成員再點擊「**加入成員名單**」。
* 啟用權限設定後，有被加入的成員才可讀寫此儲存空間。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img5.png）

## 管理資料夾／檔案
### 建立資料夾
* 進入儲存體的內容列表頁面，點擊上方命令列的建立資料夾圖示。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img6.png）

* 輸入資料夾名稱後按下「**確定**」。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img7.png）

### 上傳檔案
* 進入儲存體的內容列表頁面，點擊上方命令列的上傳圖示。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img8.png）

* 出現「**上傳**」視窗後可以直接將檔案或資料夾拖曳至此，或點擊「**選擇檔案**」再選取欲上傳的檔案，選擇完成後再點擊「**上傳**」。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img9.png）

* 上傳成功後回到內容列表頁面，會顯示檔案名稱、大小及更新日期等資訊。

### 刪除檔案
* 點擊列表右側的更多選項圖示，再點擊「**刪除**」。

### 複製檔案／資料夾名稱
* 點擊檔案或資料夾名稱右側的複製圖示，可複製檔案／資料夾名稱。

### 搜尋檔案
* 在搜尋框中輸入欲查詢的關鍵字，可篩選出符合的項目。

## 其他存取方式
本服務除了可透過使用者介面存取之外，另外提供了 S3、SFTP 以及 FTP 存取方式，方便管理大量或較大的檔案。

### S3 存取方式
#### 1. 下載並安裝 Amazon S3 相容的第三方軟體
* Windows：使用 [**S3 Browser**](http://s3browser.com/) 
* MacOS：使用 [**Cyberduck**](https://cyberduck.io/)
* Linux（命令列模式）：使用 [**Rclone**](https://rclone.org/)

#### 2. 取得連線的服務端點
（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img15.png）

* 將滑鼠移至服務據點右側的提示圖示，會顯示 S3、FTP、SFTP 的設定資訊。
    
    
#### 3. 取得 S3 連線的 Access Key 及 Secret Key 
* 點擊右上角的使用者名稱，再點選 **金鑰**。
* 接著點擊左側選單之 **S3 金鑰**，進入 S3 連線資訊頁面。
* S3 連線資訊頁面提供 Signature Version、Access Key 及 Secret Key 等第三方軟體所需的設定資訊。
* 點選右上方「**更新金鑰**」可更新您的金鑰。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img12.png）

:::info
:bulb:**金鑰使用提示**
1. 此 S3 金鑰無預設期限，一旦在第三方軟體中設定好，下次開啟第三方軟體時直接連線即可。
2. 請妥善保管您的金鑰，或定期更新金鑰，以防金鑰外流。金鑰更新後，請記得更新第三方軟體中的金鑰設定。
:::

#### 4. 連線檔案傳輸節點
* 使用 Amazon S3 相容的第三方軟體連線檔案傳輸節點，以下是 S3 Browser 的設定：
	- Account Type：S3 Compatible Storage
	- REST Endpoint：服務端點 **`release.trusted-cloud.nchc.org.tw`**　
	- Access Key ID：**S3 連線資訊** 頁面所提供的 Access Key
	- Secret Access Key：**S3 連線資訊** 頁面所提供的 Secret Key
	- Use secure transfer (SSL/TLS)：請勾選此選項
	- Signature Version（Advanced S3-compatible storage settings）：Signature V4

#### 5. 連線成功後，遠端站台將顯示此專案的儲存體。

### FTP 存取方式
#### 0. 必要條件
* 請確認您的帳號已啟用 [**雙重驗證設定**](/s/2fa)。

#### 1. 下載並安裝支援交談式登入型式的 SFTP 連線軟體
* 例如：[**FileZilla**](https://filezilla-project.org/) 或 [**Cyberduck**](https://cyberduck.io/)。
    
#### 2. 取得連線的服務端點
* 請複製管理頁面右上角的服務據點，此即為連線的服務端點。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img15.png）

* 將滑鼠移至服務據點右側的提示圖示，會顯示連接埠設定資訊。

    

#### 3. 連線檔案傳輸節點
* 請在支援交談式登入型式的 FTP 連線軟體上設定：
    - 協定：FTP
    - 連接埠：21
    - 主機：**`release.trusted-cloud.nchc.org.tw`**
    - 登入型式：交談式
    - 使用者／密碼：
        * iService 使用者請輸入您的主機帳號及主機密碼＋OTP驗證碼
        * 測試使用者請輸入平台測試帳號及登入密碼＋OTP驗證碼
:::info 
:bulb: **FTP 使用提示**
* FTP 的密碼需輸入 **密碼＋OTP驗證碼**。
* 機敏資料建議使用 SFTP 存取方式。

:::
#### 4. 連線成功後，遠端站台將顯示您加入的全部專案。

### SFTP 存取方式
#### 0. 必要條件
* 請確認您的帳號已啟用 [**雙重驗證設定**](/s/2fa)。

#### 1. 下載並安裝支援交談式登入型式的 SFTP 連線軟體
* Windows：使用 [**FileZilla**](https://filezilla-project.org/) 或 [**Cyberduck**](https://cyberduck.io/)。
* Linux（命令列模式）：使用 SFTP 指令。

#### 2. 取得連線的服務端點
* 請複製管理頁面右上角的服務據點，此即為連線的服務端點。

（見圖:./output/image/3.可信賴雲服務/3.可信賴雲服務_3.5資料攜出_img15.png）

* 將滑鼠移至服務據點右側的提示圖示，會顯示連接埠設定資訊。

    

#### 3. 連線檔案傳輸節點
* 請在支援交談式登入型式的 SFTP 連線軟體上設定：
    - 協定：SFTP
    - 連接埠：22
    - 主機：**`release.trusted-cloud.nchc.org.tw`**
    - 登入型式：交談式
    - 使用者／密碼：
        * iService 使用者請輸入您的主機帳號及主機密碼
        * 測試使用者請輸入平台測試帳號及登入密碼
    - OTP 密碼：驗證器應用程式產生的 6 位驗證碼

#### 4. 連線成功後，遠端站台將顯示您加入的全部專案。
