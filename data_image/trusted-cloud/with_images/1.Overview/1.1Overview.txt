# Overview
## User interface
The platform provides cloud resource services and management tools and integrates HPC and SeniMesh resources. After successfully logging in, you can enter the homepage of the user interface and start using various services.

:::info
:bulb: **Tip:** The following figure shows the services provided by the Public Portal. The services and functions provided by the Private Portal may be different. Please refer to the user guide of each service for details.
:::
（Image:./trusted-cloud/image/1.Overview/1.Overview_1.1Overview_img1.png）

1. Cloud platform logo: Return to the platform homepage.
2. Service list: quickly switch services.
3. Select a project: Please select a specific project before using each service.
4. Set the language to **Chinese** or **English**.
5. Documentation: Provide instructions for using the cloud platform.
6. Select zone: Select **Trusted Cloud** or **SensiMesh**.
:::info
:bulb: **Tip:** The services provided by different resource zone may be different.
:::
8. Account: Provides account-related information and related functions.
9. Current project name and project ID
10. Frequent services
11. Overview of services

## Roles and permissions
There are three roles in this platform:
| Roles | Permissions |
| ------------------------ | ---- |
| Platform Manager (Site Admin) | Can control the resources of all tenants and all tenant users on the cloud platform. |
| Tenant Admin |Can manage the resources of all users under his/her project. |
| Tenant User | Can create and view the resources used by the project. |
