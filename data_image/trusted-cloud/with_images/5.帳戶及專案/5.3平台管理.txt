# 平台管理
* 點擊右上角的使用者名稱，再點選 **平台管理** 進入平台管理頁面。

:::info
:bulb:**提示：** 此功能需具備 **系統管理員** 或 **平台管理員** 權限。
:::

## 選擇區域
* 點擊右上角的使用者名稱左側的區域選單可切換 **可信賴雲** 或 **前導資源**。



:::info
:bulb: **提示：** 不同的區域提供的服務會有所不同。
:::
## 成員管理
提供測試使用者帳號管理及管理員權限設定。

### 測試使用者
#### 新增測試使用者
* 點選左側選單 **成員管理＞測試使用者**，進入測試使用者管理頁面後點擊「**新增**」。
* 輸入使用者的帳號、名稱、電子郵件地址等資訊後點擊「**確定**」。
    
:::info
:bulb: **提示：** 使用者帳號建立後，請記得將該使用者加入所屬的專案中。
:::

#### 管理測試使用者
* 測試使用者建立後會顯示在列表中，點擊列表右側的更多選項圖示可執行 **編輯使用者**、**變更密碼**、**專案資訊**、**複製 ID** 及 **刪除**。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img2.png）

#### 編輯使用者
* 點擊列表右側的更多選項圖示，接著點擊 **編輯使用者**，修改使用者的姓名或 Email，接著點擊「**確定**」。

:::info
:bulb: **提示：** 使用者帳號不可修改。
::: 
（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img3.png）

#### 變更密碼
* 點擊列表右側的更多選項圖示，接著點擊 **變更密碼**，輸入新的使用者的密碼後點擊「**確定**」。

#### 專案資訊
* 點擊列表右側的更多選項圖示，接著點擊 **專案資訊**。
* 在「**專案資訊**」視窗中會顯示該使用者帳號所參與的專案。

#### 複製 ID
* 點擊列表右側的更多選項圖示，接著點擊 **複製 ID** 可複製 ID 至剪貼簿中。

#### 刪除使用者
* 點擊列表右側的更多選項圖示，接著點擊 **刪除**。

### 管理員權限
#### 新增管理員
* 點選左側選單 **成員管理＞管理員權限**，進入管理員權限管理頁面後點擊「**新增**」。
* 在管理員名單欄位輸入使用者的帳號，可用逗點分隔多筆資訊，接著點擊「**加入**」。
* 勾選欲新增的權限（平台管理員、系統管理員）後點擊「**確定**」。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img4.png）

#### 管理管理員權限
* 管理員權限建立後會顯示在列表中，點擊列表右側的更多選項圖示可執行 **編輯權限** 及 **刪除**。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img5.png）

#### 編輯權限
* 點擊列表右側的更多選項圖示，接著點選 **編輯權限**，修改完成後點擊「**確定**」。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img6.png）

#### 刪除管理員權限
* 點擊列表右側的更多選項圖示，接著點擊 **刪除**。

## 網路管理
網路管理功能可匯入外部網路、設定公／私區域的預設外部網路，並可針對各專案的指定使用的外部網路。專案內產生的虛擬網路及浮動 IP 將會依其對應的外部網路取得對外 IP。

### 外部網路
#### 匯入外部網路
* 點選左側選單 **網路管理＞外部網路**，進入外部網路管理頁面。
* 選擇上方 **公區** 或 **私區** 接著點擊「**匯入**」。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img20.png）

* 完成匯入外部網路設定：
    * 外部網路：選擇外部網路。
    * 區域：選擇公區或私區。
    * 預設網路：勾選指定為預設網路。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img21.png）

#### 管理外部網路
* 外部網路匯入後會顯示在列表中．點擊列表右側的更多選項圖示可執行 **IP 使用資訊**、**預設網路設定**、**複製 ID** 及 **刪除**。　

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img22.png）

#### IP 使用資訊
* 點擊列表右側的更多選項圖示，接著點擊 **IP 使用資訊**，可查看 IP 已用量及總量。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img23.png）

#### 預設網路設定
* 點擊列表右側的更多選項圖示，接著點擊 **預設網路設定**，可設定為預設網路。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img24.png）

* 設定為預設網路後會顯示在列表的 **預設** 欄位。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img25.png）

#### 複製 ID
* 點擊列表右側的更多選項圖示，接著點擊 **複製 ID** 可複製 ID 至剪貼簿中。

#### 刪除外部網路
* 點擊列表右側的更多選項圖示，接著點擊 **刪除**。

### 專案外部網路
#### 管理專案外部網路
* 點選左側選單 **網路管理＞專案外部網路**，進入專案外部網路頁面。
* 點擊欲設定的專案列表右側的更多選項圖示，接著點擊 **網路設定**。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img26.png）

* 在專案外部網路管理視窗可選擇該專案的外部網路，包括 **公區網路** 及 **私區網路**。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img27.png）

### 實體網路
針對特殊需求，可將特定的實體網路連結至虛擬機器。
    
#### 建立實體網路
* 點選左側選單 **網路管理＞實體網路**，進入實體網路管理頁面，接著點擊「**建立**」。
* 接著完成實體網路的各項設定：
    * Provider 網路 UUID：設定 Provider 網路 UUID。
    * 名稱：輸入名稱。
    * 描述：輸入描述。
    * 安全性群組 UUID：設定安全性群組 UUID，可設定多組。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img28.png）

#### 管理實體網路
* 實體網路建立後會出現在列表中，點擊列表右側的更多選項圖示可執行 **編輯描述**、**複製 ID** 或 **刪除**。
* 點擊列表可檢視實體網路詳細資料。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img29.png）

#### 關聯／分離虛擬機器
* 在實體網路詳細資料頁面下方的 **關聯資訊** 區塊，點擊 **新增關聯**。
* 輸入 **虛擬機器 ID**，再點擊「**確定**」。
* 完成後在列表中會顯示已關聯的虛擬機器。
* 如欲分離虛擬機器可將滑鼠移至列表右側的更多選項圖示，再點擊 **分離**。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img30.png）

設定及管理系統預設的公用虛擬映像檔，包括公區及私區。

#### 準備工作

請先準備好系統預設的的虛擬映像檔，並將映像檔上傳至 [**平台管理＞系統儲存**](/s/platform-mgmt#系統儲存)。

:::warning
:warning: **注意：**
* Linux 映像檔格式如：raw、qcow2。
* Windows 映像檔格式如：vhd、vhdx、 vmdk、vdi、iso、ploop、aki、ari、ami。
* 建議使用第三方軟體上傳映像檔，傳輸容量較大、速度較快。
:::

* 點選左側選單 **雲平台服務設定＞虛擬映像檔** 進入虛擬映像檔管理頁面。
* 列表中會顯示系統預設的公用虛擬映像檔。
* 使用文件請參考 [**虛擬映像檔**](/s/vm-image)，不同的是：
    - 映像檔需先上傳到 **平台管理＞系統儲存**。
    - 此處會多出 **公區** 及 **私區** 的選項。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img37.png）

### 應用服務 APP
#### 建立應用服務 APP
* 點選左側選單 **雲平台服務設定＞應用服務 APP 管理** 進入應用服務 APP 管理頁面，接著點擊「**建立**」。
* 輸入名稱、描述及版本後點擊「**確定**」。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img38.png）

* 出現申請已成立的視窗後點擊檔案存放位置連結，並將相關的檔案上傳至指定的路徑。 

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img39.png）

#### 管理應用服務 APP 
* 點擊列表右側的更多選項圖示可執行 **複製 ID** 或 **刪除**。　

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img40.png）

#### 刪除應用服務 APP
* 點擊列表右側的更多選項圖示點選 **刪除**。
:::info
:bulb: **提示：** 刪除應用服務 APP 前，請先刪除該應用服務 APP 的所有版本。
::: 
#### 管理應用服務 APP 版本
* 點擊列表進入應用服務 APP 版本列表頁面。
* 點擊列表右側的更多選項圖示點選 **權限設定**、**檔案位置**、**複製 ID** 或 **刪除**。　

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img41.png）

#### 權限設定
* 點擊列表右側的更多選項圖示再點選 **權限設定**。
* **權限設定**：應用服務 APP 建立後系統預設為 **非公開**，點擊 **公開**，可將此應用服務 APP 開啟給所有專案。
* **開放專案**：點擊下拉選單，可勾選欲開放的專案。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img42.png）

#### 檔案位置
* 點擊列表右側的更多選項圖示再點選 **檔案位置**。
* 在視窗中會顯示檔案存放位置連結，點擊該連結可快速開啟該連結的系統儲存。

（見圖:./output/image/5.帳戶及專案/5.帳戶及專案_5.3平台管理_img43.png）

#### 複製 ID
* 點擊列表右側的更多選項圖示，接著點擊 **複製 ID** 可複製 ID 至剪貼簿中。

#### 刪除應用服務 APP 版本
* 點擊列表右側的更多選項圖示再點選 **刪除**。
