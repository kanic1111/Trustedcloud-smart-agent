# 浮動 IP
## 建立浮動 IP
* 從服務列表選擇 **虛擬網路**，再從左側選單點選 **浮動 IP** 進入浮動 IP 管理頁面，接著點擊「**＋建立**」。
* 除了手動建立浮動 IP，在其他的對外服務中亦可以選擇由系統自動配置浮動 IP。

## 管理浮動 IP
* 浮動 IP 建立後會出在列表中，列表中會顯示已關聯服務、保留、狀態及建立資訊。

（見圖:./output/image/2.虛擬平台服務/2.虛擬平台服務_2.6浮動IP_img1.png）

### 保留／解除保留浮動 IP
* 浮動 IP 預設之生命周期會等同於所關聯之服務（如虛擬機器），若所關聯服務被刪除時系統將同時刪除浮動 IP 刪除，設定保留的浮動 IP 不會被系統主動刪除。
* 點擊列表右側的更多選項圖示可選擇 **保留／解除保留** 浮動 IP。

（見圖:./output/image/2.虛擬平台服務/2.虛擬平台服務_2.6浮動IP_img2.png）

### 分離服務
* 當已關聯服務不再使用浮動 IP 時，可選擇 **分離服務** 釋出此 IP 資源。

### 刪除浮動 IP
* 點擊列表右側的更多選項圖示，再點擊 **刪除**，刪除浮動 IP 會自動分離關聯服務。

### 批次删除
* 若想快速刪除多個資源，可點擊管理頁面右上方的「**批次删除**」。
* 勾選欲刪除項目後點擊「**確定**」。
