# K8S 叢集
提供 Kubernetes 叢集服務，方便快速部署與管理容器化應用程式。

## 建立 K8S 叢集
:::warning
:warning: **注意：** 請先建立一組包含允許 ingress 6443 port 的安全群組。
:::

* 從服務列表選擇 **K8S 叢集**，進入 K8S 叢集管理頁面後，點擊「**＋建立**」。

#### 1. 基本設定
* 填寫名稱、描述並選擇 K8S 版本，接著點擊「**下一步：硬體設定＞**」。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img1.png）

#### 2. 硬體設定
* 點擊右上方的 **查看資源使用量／配額**，可檢視目前的資源配額及已用量。若可用資源配額已達上限，部分型號無法選擇，可聯繫您的系統管理員提高專案資源配額。
* 主節點數量：設定主節點數量，例如：1、3、5。
* 運算節點硬體設定：此處所提供的硬體型號選項會因伺服器的硬體配置而有所不同，系統管理者亦可針對專案的需求進行設定。
* 運算節點數量：設定運算節點數量，建立後可依需求增減。
* 接著點擊「**下一步：虛擬網路＞**」。

#### 3. 虛擬網路
* 配置浮動 IP
    * 不配置
    * 自動配置浮動 IP 
    * 選擇既有浮動 IP 
* 安全群組：此處的下拉選單會自動篩選出包含 ingress 6443 port 的安全群組，請選取一組包含允許 ingress 6443 port 的安全群組。
* 接著點擊「**下一步：檢閱＋建立＞**」。

:::info
:bulb: **提示：** 建立 K8S 叢集時會自動建立一組獨立的虛擬網路。
:::
（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img2.png）

#### 4. 檢閱＋建立
* 檢查建立設定，確定後點擊「**建立**」。

## 管理 K8S 叢集
* K8S 叢集建立後會出現在列表中，建立叢集需要一些時間，當狀態顯示為 **`ready`** 即可開始使用。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img3.png）

:::info
:bulb: **提示：** 當狀態顯示為 **`under review`** 時，表示此資源需通過專案管理者審核准後才可建立。專案管理者可透過下面兩種操作核准或拒絕建立該資源。
1. 在管理列表頁面，點擊更多選項圖示，接著點擊 **審核**。
2. 點擊上方命令列的 （見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img4.png） **審核** 圖示。
:::
 
* 點擊列表右側的更多選項圖示，可執行 **新增運算節點**、**版本升級**、**配置浮動 IP**、**複製服務 ID**、或 **刪除**。
* 點擊列表可檢視 K8S 叢集詳細資料。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img5.png）

### 連線與網路資訊
* 在 **連線與網路資訊** 區塊可檢視虛擬網路、API 伺服器端點資訊及安全群組等設定。
* 虛擬網路名稱：系統為 K8S 叢集自動建立的虛擬網路，詳細資訊可至虛擬網路服務中查看。
* API 伺服器端點：K8S 叢集 API 伺服器端點的端點資訊。
* 安全群組：安全群組，點擊安全群組右側的「**變更**」，選擇安全群組後點擊「**確定**」。
* kubeconfig：K8S 叢集的設定檔，點擊 kubeconfig 右側的「**下載**」，可下載此檔案。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img6.png）

* 再次點擊「**下載**」，下載後請妥善保存，此檔案只能下載一次。若沒有此檔案，將無法連線。
 
（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img7.png）

:::warning
warning: **注意：** kubeconfig 下載後請妥善保存，一旦遺失將無法再重新下載。
:::

:::info
:bulb: **提示：** K8S 叢集管理工具 - kubectl  
kubectl 是 Kubernetes 命令列工具，可管理 K8S 叢集、部署應用程式、檢視和管理叢集資源，以及查看日誌。安裝及使用說明請參考 [**Kubernetes 官網**](https://kubernetes.io/docs/tasks/tools/#kubectl)。
:::    

### 更新 K8S 版本
* 在 K8S 叢集詳細資料頁面，點擊上方的 **更新 K8S 版本** 圖示。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img8.png）

* 確定升級的版本後點擊「**升級**」。 
:::info
:bulb: **提示：** 每次更新只能升級一個版本。
:::
（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img9.png）

* 版本升級需要一些時間，當狀態顯示為 **`ready`** 即可開始使用。

### 查看日誌
* 在 K8S 叢集詳細資料頁面，點擊上方的 **查看日誌** 圖示。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img10.png）

### 刪除 K8S 叢集
* 在 K8S 叢集詳細資料頁面，點擊上方的 **刪除** 圖示。

### 運算節點群組
* 進入 K8S 叢集詳細資料頁面，接著點擊上方的 **運算節點群組** 頁籤，可檢視目前的運算群組資訊。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img11.png）

### 新增運算節點群組
* 點擊「**＋建立**」可新增運算節點群組，設定完成後點擊「**確定**」。
    - 叢集名稱：叢集名稱，系統自動帶入。
    - 名稱：輸入運算節點群組名稱。
    - 硬體設定：選擇運算節點硬體設定。
    - 運算節點數量：設定運算節點數量，建立後可依需求增減。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img12.png）

### 變更運算節點數量
* 將滑鼠移至右側的更多選項圖示再點選 **變更數量**。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img13.png）

* 輸入欲變更的運算節點數量後點擊「**確定**」。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img14.png）

### 審核列表
* 當新增的運算節點群組資源需要經過審核時，會顯示在審核列表，狀態會顯示為 **`under review`**，需等待專案管理者審核准後才可建立。
* 專案管理者可點擊列表右側的更多選項圖示，接著點擊 **審核**。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img15.png）

### 監控
* 進入 K8S 叢集詳細資料頁面，接著點擊上方的 **監控** 頁籤即可查看監控指標。
* 點擊上方的時間選單可變更欲查看的時間區間；點擊節點選單可變更欲查看的節點。

（見圖:./output/image/4.容器與其他服務/4.容器與其他服務_4.1K8S叢集_img16.png）
