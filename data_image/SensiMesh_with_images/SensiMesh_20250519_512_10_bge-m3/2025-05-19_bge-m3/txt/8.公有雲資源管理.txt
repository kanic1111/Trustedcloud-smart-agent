8  公有雲資源管理
公有雲資源經由平台管理者（或經開放之租 戶 管理者），目前提供 AWS 公有雲支援。
8.1  租 戶 管理者建立或修改 Cloud Provider 認證
透過平台管理者可將使用者介面的 Cloud Provider 認證 啟 用，專案管理者登入後切換至
Management > Cloud Providers 設定是否 啟 用公有雲並對認證做更新、修改或刪除等管理。
8.2  切換至公有雲資源管理
切換 Cloud Provider 至 AWS 後可管理公有雲資源，建立虛擬步驟與本地資源一致。
● 於 Cloud Providers 下切換至公有雲資源（本地資源為 CUBE ）
8.3  建立虛擬主機
● 切換至 aws cloud providers
● 建立新 instance
● 選擇區域與印像檔
● 選擇規格
● 設定密碼或 ssh
● 設定 instance  名稱與 tag
● 點選建立創建
● 創建完成
8.4  管理虛擬磁碟
● 建立新硬碟，點選 Add Volume  或 Create Volume
● 選擇規格、掛載的虛擬機，輸入名稱後，點選建立
● 建立完成
● 確認有新增此硬碟
8.5  管理網路資源
網路資源管理與本地服務一致，浮動位址 (non-reserved) 在 AWS 虛擬主機建立時即 產 生，
透過浮動位址管理可建立保留用位址 (reserved) 供後續使用。
8.5.1  浮動位址管理
● 在下拉選單選擇虛擬主機，點擊 Reserve and Assign Floating IP
● 申請的 FIP  成功綁定虛擬主機
8.5.2  防火牆管理
同理 Cube provider  的防火牆管理。
● 新增防火牆，先點擊 Add Firewall
● 標示名稱
● 建立規則
● 輸入允許的連線 (0.0.0.0/0  代表不限制 IP  拜訪 )
● 選擇套用的虛擬機並建立
● 完成建立
可於防火牆頁面或是虛擬機頁面確認有成功套用防火牆
● 點擊防火牆，可展開防火牆訊息
● 可確認套用之虛擬機，也可新增套用之虛擬機
● 可於虛擬機確認所套用的防火牆
8.6  建立 Kubernetes 叢集
● 在管理選單點選 Kubernetes,  按下 + Add Cluster
8.6.1 Kubernetes 版本與網路設定
● 選擇公有雲 Region
● 選擇 Kubernetes 版本
● 選擇網路（預設 Kubernetes 網路）
註：僅提供指定版本及專用網路
8.6.2  選擇容量與節點池
● 設定節點池與節點數量
○ 預設建立 master  與 worker  節點池
○ 預設叢集節點於各節點池為 1  節點
○ 可另行設定節點數量
○ 可設定節點角色
○ 可另行增加節點池
8.6.3  開始建立叢集
● 輸入叢集名稱
● 輸入叢集標籤（可留空白或填入一個或多個）
● 輸入完畢按下 Create Cluster 開始建立叢集
8.6.4  完成叢集建立
● Kubernetes 叢集清單顯示狀態
● 完成後狀態更新為可用（ active ）
管理 Kubernetes 叢集與進階使用操作叢集可參考 「 管理 Kubernetes 叢集 」 與「 進階使用操
作叢集 」，除 Kubernetes 建立於不同雲服務提供外，相關操作皆一致。
