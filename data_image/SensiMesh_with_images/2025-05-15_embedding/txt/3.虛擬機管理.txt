3.5  管理虛擬主機
3.5.1  虛擬主機相關操作
● 可於虛擬主機頁面 (Instance)  點選可用的虛擬主機進行相關操作
● 可從右方快速選單進行虛擬主機常用功能
○ Access console:  存取虛擬主機 console （僅虛擬主機擁有者可存取）
○ Enable floating IP:  啟 用浮動位址
○ Reboot:  重新開機
○ Power on:  開機
○ Power off:  關機
○ Power cycle 重置虛擬主機（ Hard Reboot ）
○ View usage:  觀察使用率
○ Modify Lifecycle:  更改資源可被使用的期限
○ Commit to app image:  將虛擬主機轉成客製化的 image ，可在 application  做使用
註：只有 project admin  可以做此操作， project member  不會看到此項目，並且只能
Commit  自己的虛擬機
○ Destroy:  刪除虛擬主機
● 也可於資源總攬頁面 (Summary -> Overview)  點選虛擬主機進行各項操作
3.5.2  虛擬主機總覽 Summary
● 於 Summary -> Overview  頁面瀏覽並搜尋虛擬主機
○ Name:  虛擬主機名稱（含規格及作業系統資訊）
○ Keypair:  虛擬主機對應金鑰（若為指定認證方式）
○ Interface IP:  網路位址
○ Floating IP:  浮動位址（若有設定）
○ Tags:  標籤（若有指定，可為一或多個）
○ Owner:  擁有者（專案管理者可 查 看所有成員虛擬主機、一般使用者 查 看個人虛擬主
機）
○ Expire:  資源到期剩餘時間
○ Created:  建立時間
○ Status:  狀態

3.8.3.1  負載平衡服務的進階選項
針對各服務協定，可調整前端連線 (frontend) 或後段連線 (backend) 的逾時時間 值 ，以符
合實際需求。如：作為 SSH 連線轉埠服務可增加逾時時間維持連線。
針對 HTTP/HTTPS ，也提供加入 HTTP header 選項如： X-Forward-For
另外，每個服務皆可設置白名單限定外部存取服務，名單建立以 CIDR 形式，可以為多組
網路。
● Member Data Timeout (seconds) ：負載平衡服務至後端主機的連線資料時間，預設為 50
秒、可設定 值 為 0 至 2073600 （ 24 天），可依據實際需求調整。
● Client Data Timeout (seconds):  用 戶 端至負載平衡服務的連線資料時間，預設為 50 秒、可
設定 值 為 0 至 2073600 （ 24 天），可依據實際需求調整。
● 如需由用 戶 端調整連線逾時等設定，請參考問題排除「 排除透過負載平衡服務做轉址時
效過短問題 」，或透過 「 負載平衡服務的進階選項調整設定 」調整設定。

● 以不同埠號分別存取管理虛擬主機
● 如遇有過快逾時的問題請參考問題排除「 排除透過負載平衡服務做轉址時效過短問題 」
，或透過 「 負載平衡服務的進階選項 」，來設定延長 timeout 值
3.9  映像檔匯入及虛擬主機匯出
在映像檔選單頁面，除了可以對虛擬機快照及備份進行相關操作，如建立或還原虛擬
機，還可以根據使用者的需求上傳映像檔進行匯入，以供後續開 啟 自訂的虛擬機做使用。此
外，在運行的虛擬機選單中也提供了匯出功能，可讓使用者將虛擬機匯出以便轉移至其他
平台，或者下載至用 戶 端，作為異地備份的用途。
3.9.1  映像檔匯入
● 點選 Images 選單並切換至 Custom Images 分頁
● 已完成上傳匯入之映像檔會列於清單中
● 按下 Upload Image 選擇用 戶 端之映像檔案
● 按下 Add 選擇用 戶 端檔案並確認
● （選擇性）輸入映像檔描述
● （選擇性）輸入標籤
● 完成按下 Upload 開始上傳
註：上傳需擬磁碟格式需為 vmdk, qcow2 或 img 檔案，且為可開機磁碟。
● 檔案上傳進度顯示， 100% 上傳完成後開始轉檔匯入；使用者可於任何時候取消上傳。
● 上傳完成進行轉檔作業
註：映像檔匯入時間取決於虛擬磁碟大小，實際完成時間約 30 分鐘至一小時不等。
● 完成後可指定映像檔開 啟 新的虛擬主機
● 亦可由新增虛擬主機時選擇 Custom Image 指定映像檔
3.9.2  虛擬主機匯出
● 點選指定虛擬主機進行匯出作業
● 切換至 Image Export 分頁
● 點擊 Export 按鍵， CMP 會把虛擬機的硬碟轉成檔案
● 按下 Export 確認開始進行虛擬主機匯出作業；或按 Cancel 取消離開
● 開始進行虛擬主機匯出作業
註：
1.  虛擬主機匯出包含格式轉換、壓縮等相關流程，執行時間因磁碟大小及數量而異，實際完
成時間約一小時或以上。
2.  磁碟大小超過 200GB 無法做虛擬主機匯出作業，匯出檔案格式為 vmdk 且保留天數為一週。
● 完成後可下載至用 戶 端做後續用途
● 匯出映像檔超過七天即無法下載，系統亦不保留
