4  應用服務 App 管理
4.1  建立應用服務 App
● 在管理選單點 Applications,  按下 + Add Application
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page84_img162.png）
Application image 設定
● 選擇 Application image  類別
○ 下方預設 Application image 僅供參考 .  實際上 ,  租 戶 管理者會根據租 戶 使用者的需求 ,
依此建置各自所需的應用服務 App.
○ Application image 會有 GPU 支援與否之分別
○ GPU 的支援與否 ,  取決於租 戶 管理者製作 Application image  時 ,  決定開 啟 或關閉
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page84_img163.png）
4.1.1  樣板設定
● 選擇 Application  樣板（硬體類別及規格）
○ 下方預設樣板僅供參考 ,  實際樣板會根據國網中心調整而有所不同
○ 樣板會有 GPU 支援與否之分別
○ 是否支援 GPU,  取決於國網中心的樣板製作者
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page85_img164.png）
4.1.2  網路設定
● 選擇 Application 網路
○ 網路預設提供對外網路以及 內 部網路
○ Floating IP( 對外網路 ),  即 Application 建立後 ,  可直接被網際網路上的任何資源存取
○ Private IP( 內 部網路 ),  即 Application 建立後 ,  僅能被專案下的 內 網資源存取
○ 可 啟 動 Web Console,  提供 Application 終端操作介面
○ 可 啟 用 Allowed CIDRs,  限制 Application 資源存取的來源 .
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page86_img165.png）
4.1.3 SSH  驗證設定
● ( 選擇性 )  選擇 Key-pair 來決定 啟 用 SSH 連線與否
○ 是否支援 SSH 連線 ,  取決於國網中心的樣板製作者
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page86_img166.png）
4.1.4  虛擬磁碟設定
● ( 選擇性 )  選擇外接虛擬磁碟
○ Create New Volume,  即 Application  建立後 ,  自動建立新虛擬磁碟並掛載於指定的
mount point
○ Existing Volume,  即 Application 建立後 ,  自動將既有的虛擬磁碟掛載於指定的 mount
point
○ 一個 Application 最多僅能掛載 5 個外接虛擬磁碟
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page87_img167.png）
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page87_img168.png）
4.1.5  環境變數設定
● ( 選擇性 )  預先設置環境變數
○ 一個 Application,  最多僅能建立 10 個預設環境變數 .
4.1.6  開始建立 Application
● 輸入 Application 名稱
● ( 選擇性 )  輸入資源申請資訊
○ 是否需填寫資源申請資訊 ,  取決與國網中心是否開 啟 此限制
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page88_img169.png）
4.1.7  完成 Application 建立
● Application 清單顯示資源建立中的狀態
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page89_img170.png）
● 完成後狀態更新為可用（ active)
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page89_img171.png）
4.2  管理應用服務 App
4.2.1  應用服務 App 相關操作
● 點選可用 Application 進行相關操作
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page90_img172.png）
● 可從右方快速選單操作 Application 常用功能
○ Enable/Disable access console:  開 啟 / 關閉 Application console （僅 Application 擁有者可
存取）
○ Enable/Disable floating IP:  啟 用浮動位址
○ Suspend:  暫停 Application
○ Edit allowed CIDR:  更改資源存取來源
○ View log:  觀看 Application 運行日誌
○ Commit to app image:  將 Application 轉成客製化的 Application image
○ Destroy:  刪除 Application
4.2.2  應用服務 App 總覽
● 於 Applications 頁面瀏覽並搜尋 Application
○ Name: Application 名稱（含規格及作業系統資訊）
○ Access link:  應用服務存取位址
○ Web console:  應用服務的 Web console 存取位址
○ Owner:  擁有者 ( 專案管理者可 查 看所有成員 Application 、一般使用者 查 看個人
Application)
○ Created:  建立時間
○ Expire:  資源到期剩餘時間
○ Status:  狀態
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page91_img173.png）
4.2.3  檢視連線位置
● 點擊 Application,  並於細節總覽上方檢視各項連線資源
○ Access link:  應用服務存取位址
○ Web console:  應用服務的 Web console 存取位址
4.2.4  檢視磁碟
● 於 Volume 分頁檢視虛擬磁碟
○ Application 掛載之磁碟 ,  無法於 Application 還存在時進行任何操作
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page92_img174.png）
4.2.5  管理狀態
● 於 State 分頁進行 Application 操作
○ 提供 Suspend  以及 Resume  操作
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page92_img175.png）
4.2.6  管理網路
● 於 Networking 分頁進行網路設定操作
○ Network:  若 啟 用 Floating IP,  則會顯示 Public Network.  否則會顯示 Private Network
○ Allowed CIDRs:  調整 Application 存取來源限制
○ Load balancer:  跳轉至 Load balancer 操作頁面
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page93_img176.png）
4.2.7  檢視日誌
● 於 Logging 分頁進行虛擬磁碟操作
○ 僅顯示最新的 200 行 Application 日誌
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page93_img177.png）
4.2.8  刪除 Application
● 於 Destroy 分頁刪除 Application
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page94_img178.png）
4.3  建立應用服務 App Image
4.3.1  建立專案預設 App Image
● 專案預設 App image ,  係指由租 戶 管理者從 VM 封裝而成的 App image
● 根據虛擬機管理章節的 說 明建立一虛擬機 ,  並佈署預計提供的應用服務
○ 若虛擬機映像檔非源自於 Bigstack 或其他雲平台大廠 ,  則需檢 查 虛擬機 內 部是否含
有 cloud-init 套件 .  若缺少該套件 ,  請參 閱 cloud-init  官方文件進行裝設
https://cloud-init.io/
● 點選虛擬機右側選單下的 Commit app image,  進入 application image  製作過程
● 於跳出視窗中 ,  填入預先設置完的服務 runtime 類別以及連線資訊 ,  以便 App 環境初始化
● 按下 commit,  建立專案預設 App image.
○ Image name: app image 名稱
○ Tag: app image 的 tag 名稱
○ Description: app image 的 說 明
○ Export ports:  服務存取協定與協定埠
○ SSH enabled:  是否提供 SSH 連線 ( 取決於 App image 製作時是否有安裝 SSH)
○ SSH username:  預設置的 SSH 連線帳號 ( 取決於 App image 製作時是否有相關設置 )
○ Container runtime:  內 置服務使用何種機制運行 ( 目前僅支援 docker  與 systemd)
○ Container name:  內 置服務的服務名稱
○ Image icon:  服務圖示
○ GPU enabled:  預設置的服務是否支援 GPU 運算
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page95_img179.png）
4.3.2  建立專案客製化 App Image
● 專案客製化 App image ,  係指由租 戶 使用者從既有 Application 封裝而成的 App image
● 根據應用服務 App 建立章節的 說 明 ,  建立 Application,  並添加任何客製化之資源或設定
● 點選 Application 右側選單下的 Commit app image,  進入 application image  製作過程
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page96_img180.png）
● 於跳出視窗中 ,  填入預先設置完的服務 runtime 類別以及連線資訊 ,  以便 App 環境初始化
● 按下 commit,  建立專案預設 App image.
○ Image name: app image 名稱
○ Tag: app image 的 tag 名稱
○ Description: app image 的 說 明
○ Image icon:  服務圖示
○ GPU enabled:  預設置的服務是否支援 GPU 運算
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page96_img181.png）
4.4  管理應用服務 App Image
4.4.1  應用服務 App Image 相關操作
● 在管理選單點 Applications,  並切換至 Images 分頁
○ Transfer:  移轉 Application image 至隱私區
○ Create application:  使用該 Application image 建立應用服務 App
○ Delete:  刪除 Application image
（見圖：./pdf_embed/SensiMesh_with_images/2025-05-15_embedding/images/page97_img182.png）
4.4.2  應用服務 App Image 總覽
● 在管理選單點 Applications,  並切換至 Images 分頁
○ Name: Application image 名稱
○ Tag: Application image 之標籤名稱
○ Service:  提供之服務類別
○ SSH enabled:  是否支援 SSH 連線 ( 取決於 Application image 製作者是否設置該項目 )
○ Size: Application image 大小
○ Category: Application image 屬於專案預設版 ,  或是專案客製化版
○ Create at:  多久前建立
○ Status: Application image 狀態
